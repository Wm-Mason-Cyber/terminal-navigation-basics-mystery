COMMAND CHEAT SHEET:
  pwd            print working directory (where am I?)
  ls             list files here
  ls -lAh        list ALL files including hidden ones
  cd <dir>       enter a directory
  cd ..          go up one level
  cd ../..       go up two levels
  cd ~           go home
  cd /           go to root of the filesystem
  cd -           jump back to previous directory
  cat <file>     read a file
  whoami         who am I logged in as?
  history        see all commands typed this session
  !!             repeat last command

TAB KEY:  press tab to autocomplete long filenames!
UP/DOWN:  scroll through previous commands
